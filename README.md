[One Sentence, One Journey](https://make.fun/bounty/u-gudril-cool-one-sentence-one-journey-410686ca)
bounty on [make.fun](https://make.fun).

## The story

> When the last ferry left the island, Mara rowed after it in her
> grandfather's leaking boat, following the gulls through a storm that tore her
> map to ribbons, until the lighthouse she had always feared turned out to be
> her own front porch light.

One sentence, 244 characters: a departure (the missed ferry), a turn (the
storm that tears the map), and an arrival somewhere unexpected (home was the
lighthouse all along).

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

Deterministic: the program always writes the same crafted sentence. No
network, no input files, no dependencies beyond Python 3.
